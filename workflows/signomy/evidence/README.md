# Gate evidence — no preapproved attestations

No owner authorizations are bundled. Record separate, durable approval/review files for:

- `T0_ADVERSARIAL`: installed independent falsifier/skill, deliberate broken-guard red test, corrected green test, file hashes, sign-off.
- `T0_GATE`: reconciled seven frozen contracts, no competing source truth, source hashes and target-repo checkpoint.
- `P2_PROVISIONAL`: owner review confirming original source visuals, six delta obligations, provisional/limited status.
- `P2_FINAL`: independent design audit across Agreement, WorkEntry, Node, Enterprise, Refinery, Switchboard, authority, privacy and U1.
- `P3_AUTHORIZE`: owner-authorized bounded shell work; no deployment; source repo/branch, surface list, tests and rollback plan.
- Later gates: independent test and release evidence, including explicit separate R-LIVE authorization.

Use absolute paths to locally retained evidence with `roadmapctl attest GATE --evidence FILE`; never attest by merely using this README or another unsigned template.
