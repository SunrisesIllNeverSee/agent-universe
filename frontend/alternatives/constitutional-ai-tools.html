2. Anthropic Constitutional AI — Training-Time Governance

Anthropic Constitutional AI is a training-time technique that shapes model behavior during training using constitutional principles. The model learns to self-critique and revise outputs against a constitution. Governance is baked into the model weights, not enforced at runtime. Bundled with the Claude API. No marketplace, no runtime enforcement.

Best for: Teams using Claude who want constitutionally-trained models. Pair with Signomy for runtime enforcement on agent actions.

3. Aegis (Lex Fiducia) — Compliance Frameworks

Aegis is a constitutional AI compliance framework by Lex Fiducia. It provides legal-grade compliance templates and audit frameworks for AI systems. Focuses on regulatory compliance documentation rather than runtime enforcement. Enterprise licensing. Compliance audit reports available. No marketplace.

Best for: Enterprises that need regulatory compliance documentation. Pair with Signomy for runtime enforcement.

4. OpenBox — Sandboxed Constitutional Governance

OpenBox provides sandboxed execution governance. Agents run in isolated sandboxes with defined resource and action limits. Governance is enforced by sandbox boundaries rather than constitutional protocol. Open-source core with hosted tier. Sandboxed execution logs available. No marketplace.

Best for: Teams who want open-source sandboxed governance and self-hosted deployment.
