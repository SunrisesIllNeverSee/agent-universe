Six Fold Flame Checker

Test whether an action would pass the Six Fold Flame — the constitutional governance check enforced by MO§ES™. Answer all six laws. If any one fails, the action is blocked before it executes.

    The six laws

    The Six Fold Flame is the constitutional test every agent action must pass before execution. MO§ES™ enforces these six laws at the execution layer — not as advisory policy, but as a hard gate. An action that fails any single law is blocked before it runs, with a SHA-256 provenance seed logging the decision.

    How enforcement works

    When an agent attempts a state-modifying action, MO§ES™ classifies the action by risk, then runs it through the Six Fold Flame. Each law is evaluated as a binary check — pass or fail. If all six pass, the action is permitted and logged with a SHA-256 provenance seed. If any law fails, the action is blocked and the failure is recorded in the audit trail. There is no partial pass. There is no override for five-out-of-six. Constitutional integrity is all-or-nothing by design.
