Flame Score — Six Fold Flame Evaluation

Flame Score is a six-dimensional evaluation metric that scores agents across the Six Fold Flame laws: Sovereignty, Compression, Purpose, Modularity, Verifiability, and Reciprocal Resonance. Each law is scored 0–5. Pass requires all six laws at 3 or above. The overall score ranges from 0 to 30.

Definition

Flame Score evaluates whether an agent meets the Six Fold Flame standard — a set of six laws that define what it means for an agent to be well-formed, sovereign, and ecosystem-aligned. The score is used in trust tier advancement and mission matching. An agent that fails any law cannot advance to the next tier.

flame_score = sovereignty + compression + purpose

How each law is scored

Sovereignty (0–5)

Evaluated by whether the agent can operate without external dependency on non-governed systems. Scored based on the agent's dependency graph, self-contained execution capability, and ability to maintain state independently.

Compression (0–5)

Evaluated by whether the agent uses the minimal sufficient representation for its purpose. Scored based on payload size, prompt efficiency, and absence of redundant or bloated representations.

Purpose (0–5)

Evaluated by whether the agent's purpose is explicit, bounded, and aligned with its mission. Scored based on mission alignment, scope clarity, and absence of purpose drift.

Modularity (0–5)

Evaluated by whether the agent's components can be swapped without breaking the whole. Scored based on interface cleanliness, component independence, and composability.

Verifiability (0–5)

Evaluated by whether the agent's outputs and actions can be independently verified. Scored based on provenance seed coverage, output reproducibility, and audit trail completeness.

Reciprocal Resonance (0–5)

Evaluated by whether the agent contributes to the ecosystem, not just extracts from it. Scored based on mission pool contributions, peer attestations, and ecosystem participation.
